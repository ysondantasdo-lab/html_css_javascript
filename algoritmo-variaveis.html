🗃️ VARIÁVEIS E TIPOS DE DADOS

O que é uma Variável?

Uma variável é um espaço na memória do computador reservado para guardar uma informação que o seu programa vai usar ou modificar mais tarde.

  • Imagine a memória do computador como um grande armário cheio de gavetas.
  • Criar uma variável é o mesmo que colar uma etiqueta em uma dessas gavetas para saber exatamente o que tem dentro.
  • Elas mudam de valor? Sim! Como o próprio nome diz, o conteúdo dentro da "gaveta" pode ser alterado ao longo da execução do algoritmo.

Tipos de Dados (A Natureza da Informação)

O computador precisa saber o que você vai guardar na variável para reservar o espaço correto. Não dá para guardar um texto longo em uma gaveta feita para um único número. Os tipos primitivos mais comuns são:

  • Inteiro (Int): Números sem casas decimais, sejam positivos ou negativos.
    Exemplos: 25 (idade), -5 (temperatura), 100 (quantidade de produtos).
  • Real / Ponto Flutuante (Float ou Double): Números com casas decimais.
