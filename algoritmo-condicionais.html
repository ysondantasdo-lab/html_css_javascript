🔀 ESTRUTURAS CONDICIONAIS

Condicional Simples: O "Se" (if)

É a estrutura mais básica. O computador avalia uma condição (que sempre resulta em Verdadeiro ou Falso). Se ela for verdadeira, ele executa um bloco de código. Se for falsa, ele simplesmente ignora e segue a vida. 

se (temperatura > 30)
    escreva("Ligar o ar-condicionado.")
fimSe

Condicional Composta: O "Se / Senão" (if / else)

Aqui nós damos uma alternativa para o computador. Criamos dois caminhos mutuamente exclusivos: se a condição for verdadeira, faça o caminho A; senão (se for falsa), faça o caminho B. É impossível o computador rodar os dois caminhos ao mesmo tempo. 

se (notaFinal >= 6.0) entao
    escreva("Parabéns, você foi aprovado!")
senao
    escreva("Você ficou de recuperação. Estude mais!")
fimSe

Condicional Encadeada: O "Se / Senão Se" (if / else if)

E se você tiver mais de duas opções? É aí que encadeamos (empilhamos) várias condições. O computador vai testando uma por uma, de cima para baixo. Assim que ele encontra a primeira verdadeira, ele executa o bloco dela e ignora todo o resto que vem abaixo. 

se (idade < 12) entao
    escreva("Categoria: Infantil")
senao se (idade >= 12 E idade < 18) entao
    escreva("Categoria: Juvenil")
senao
    escreva("Categoria: Adulto")
fimSe

Condicional de Escolha: O "Escolha / Caso" (switch / case)

Quando você precisa testar uma única variável contra vários valores específicos (como um menu de opções), usar vários Senão Se deixa o código feio e lento. Para isso serve o Escolha. Ele vai direto ao ponto. 

escolha (opcaoMenu)
    caso 1:
        escreva("Acessando o saldo da conta...")
    caso 2:
        escreva("Fazendo uma transferência...")
    caso 3:
        escreva("Saindo do sistema...")
    padrao: // Executa se o usuário digitar qualquer outra coisa
        escreva("Opção inválida!")
fimEscolha
