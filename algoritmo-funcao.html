🧩 Modularização - blocos de código reaproveitáveis

Função (Sub-rotina que retorna valor)

Do ponto de vista técnico, uma Função é um bloco de código (sub-rotina) encapsulado que processa dados de entrada e retorna obrigatoriamente um único valor. O tipo de dado do retorno deve ser especificado logo na declaração da função. Ela é tratada pelo compilador como uma expressão que se resolve em um valor, o que significa que você pode atribuí-la diretamente a uma variável.

funcao calcular_media(real n1, real n2) : real
inicio
    real resultado
    resultado <- (n1 + n2) / 2    
    // OBRIGATÓRIO: Devolve o valor processado para quem chamou
    retorne resultado 
fimfuncao
// PROGRAMA PRINCIPAL
inicio
    real media_final    
    // A função é chamada e seu retorno é guardado em uma variável
    media_final <- calcular_media(8.5, 7.5) 
    escreva("A média do aluno é: ", media_final)
fim

Procedimento (Sub-rotina vazia / Void)

Um Procedimento é uma sub-rotina que executa uma sequência de instruções ou tarefas específicas, mas não retorna nenhum valor ou tipo de dado ao programa principal. Tecnicamente, ele serve para modularizar ações repetitivas, como limpezas de memória, formatação de saídas de texto ou modificações diretas em estruturas por referência. Em linguagens baseadas em C, ele equivale a uma função com o tipo de retorno void.

procedimento exibir_cabecalho(cadeia nome_módulo)
inicio
    escreval("=======================================")
    escreval("   SISTEMA DE ALGORITMOS INTERMEDIÁRIOS")
    escreval("   MÓDULO: ", nome_módulo)
    escreval("=======================================")
fimprocedimento
// PROGRAMA PRINCIPAL
var
    cadeia texto_usuario // Declara variável
inicio
    // O procedimento é invocado
    exibir_cabecalho("Funções e Procedimentos") 
    escreva("Código rodando com sucesso...")
fim
