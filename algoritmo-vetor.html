O que são Arrays(Inglês) ou Vetor(Português)

Imagine que você precisa guardar a nota de 50 alunos. Criar 50 variáveis diferentes (nota1, nota2, ..., nota50) seria um pesadelo. O array resolve isso criando uma única variável que reserva vários espaços seguidos na memória do computador..

Existem duas regras de ouro para os arrays:

Homogeneidade: Todos os elementos devem ser do mesmo tipo
(apenas números inteiros, apenas textos, etc.).
Tamanho Fixo: Você deve definir o tamanho do array no momento da criação
(na maioria das linguagens tradicionais).
