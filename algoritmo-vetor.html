O que são Arrays(Inglês) ou Vetor(Português)

Imagine que você precisa guardar a nota de 50 alunos. Criar 50 variáveis diferentes (nota1, nota2, ..., nota50) seria um pesadelo. O array resolve isso criando uma única variável que reserva vários espaços seguidos na memória do computador..

Existem duas regras de ouro para os arrays:

Homogeneidade: Todos os elementos devem ser do mesmo tipo
(apenas números inteiros, apenas textos, etc.).

Tamanho Fixo: Você deve definir o tamanho do array no momento da criação
(na maioria das linguagens tradicionais).

Vetores vs. Matrizes

A principal diferença entre eles é o número de dimensões (direções) que usamos para acessar os dados.

Características Vetor 1D Vetor 2D ou mais
Dimensões 1 dimensão (linha única) 2 ou mais dimensões (linhas e colunas)
Identificação Usa apenas um índice: vetor[i] Usa dois ou mais índices: matriz[linha][coluna]
Uso Comum Listas de compras, histórico de notas Tabelas de dados, pixels de imagem

Vetores (Arrays 1D)

Um vetor funciona como uma linha de dados. O conceito mais importante aqui é o Índice (Index), que é a posição do elemento.

Em programação, a contagem quase sempre começa no zero (0). Se um vetor tem tamanho 5, seus índices vão de 0 a 4.

Matrizes (Arrays 2D)

A matriz adiciona uma segunda dimensão: linhas e colunas. Para encontrar um dado, você precisa cruzar essas duas informações, exatamente como no jogo de Batalha Naval.

var matriz [3x3]: vetor [1..3, 1..3] de inteiro // Define que vai de 1 até 3.

Matrizes (Arrays 3D)

Uma matriz 2D tem Linhas e Colunas. Uma matriz 3D adiciona a Profundidade (ou páginas/camadas). É como se você tivesse uma pilha de tabelas, uma atrás da outra.

Para achar um valor em um cubo, você precisa de 3 coordenadas: matriz[camada][linha][coluna].

Matrizes (Arrays 4D)

Embora seja impossível para nós humanos desenharmos algo em 4 dimensões no papel, para o computador é apenas matemática.

Imagine uma Ordem de Passos para montar um Cubo Mágico. Cada passo guarda um cubo 3D inteiro. Para acessar, você usaria 4 índices: matriz[passo][camada][linha][coluna].

**** (1ª Dimensão): Funciona como uma linha do tempo sequencial. Cada posição dessa linha guarda um estado completo do cubo.
**** (2ª Dimensão): Escolhe qual fatia/página do cubo você está olhando naquele passo.
**** (3ª Dimensão): Localiza a horizontal (fileira) daquela fatia.
**** (4ª Dimensão): Localiza a vertical e encontra o bloquinho exato.
