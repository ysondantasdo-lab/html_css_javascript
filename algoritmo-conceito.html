👣Algoritmo

Conceito de Algoritmo

Um algoritmo é uma sequência finita de passos lógicos, claros e definidos para resolver um problema.

Como Funciona um Sistema Computacional

Dispositivos de Entrada (Input): Enviam dados do mundo externo para o sistema (teclado, mouse, arquivos, sensores, APIs)

Unidade Central de Processamento (CPU): O "cérebro". Ela possui a ULA (Unidade Lógica e Aritmética), que realiza os cálculos matemáticos e testes lógicos do seu algoritmo.

Memória (RAM): Onde o algoritmo armazena os dados temporários enquanto está rodando.

Dispositivos de Saída (Output): Apresentam o resultado processado pelo algoritmo para o usuário (tela, caixas de som, impressoras, salvamento em banco de dados).
