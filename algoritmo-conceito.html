👣Algoritmo

Conceito de Algoritmo

Um algoritmo é uma sequência finita de passos lógicos, claros e definidos para resolver um problema.

Como Funciona um Sistema Computacional

Dispositivos de Entrada (Input):

Enviam dados do mundo externo para o sistema (teclado, mouse, arquivos, sensores, APIs)

Unidade Central de Processamento (CPU):

O "cérebro". Ela possui a ULA (Unidade Lógica e Aritmética), que realiza os cálculos matemáticos e testes lógicos do seu algoritmo.

Memória (RAM):

Onde o algoritmo armazena os dados temporários enquanto está rodando.

Dispositivos de Saída (Output):

Apresentam o resultado processado pelo algoritmo para o usuário (tela, caixas de som, impressoras, salvamento em banco de dados).

Memória e Variáveis: O Mecanismo por Trás dos Panos

Quando você cria uma variável em um algoritmo, o sistema operacional reserva um endereço físico de memória (em formato hexadecimal) na memória RAM para guardar aquele valor.

Char/Caractere (1 Byte):

Guarda uma única letra ou símbolo.

Integer/Inteiro (4 Bytes):

Guarda números inteiros.

Float/Real (4 ou 8 Bytes):

Guarda números com frações (ponto flutuante).

Boolean/Lógico (1 bit/1 Byte):

Guarda apenas 0 (Falso) ou 1 (Verdadeiro).

Exemplo:

Quando você escreve idade = 25, o computador faz o seguinte mapa mental:

Nome do identificador: idade (rótulo humano).

Endereço de Memória: 0x7ffebdf56 (localização real física na RAM).

Valor: 25 (convertido para binário: 00011001).

Entrada e Saída de Dados (I/O)

A interação com o usuário é chamada de I/O (Input/Output). Sem isso, o algoritmo seria estático e processaria sempre a mesma informação.

Entrada de Dados:

Interrompe a execução do algoritmo e aguarda o usuário digitar um valor. Esse valor é lido pelo buffer do sistema e jogado para dentro da variável designada.

Saída de Dados:

Pega o valor armazenado em uma variável ou um texto fixo, converte para caracteres visíveis e envia para o dispositivo de saída (geralmente o monitor).

O Ciclo de Vida de um Algoritmo: Do Código ao Processador

Para que o computador entenda a sua lógica, o algoritmo passa por três fases:

Código-Fonte:

O algoritmo escrito por você em uma linguagem que humanos entendem (Python, C, Java, Portugol).

Compilação / Interpretação:

Um software tradutor pega o seu código-fonte e o transforma em Código de Máquina (uma sequência gigantesca de zeros e uns: 01101001).

Execução:

A CPU busca essas instruções binárias na memória RAM, decodifica o que cada uma faz (somar, mover dados, comparar) e executa nos seus circuitos eletrônicos.
